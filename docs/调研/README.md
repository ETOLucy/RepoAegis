# 调研报告

每次调研写成一篇：为什么查、方法和出处、数据（自报、实测、推断分开标）、各项目借鉴什么和不借鉴什么、据此的建议、尚未查清的。报告记录的是调研当时的结论，后来改过的决定以 `docs/` 根下的设计文档为准。下面按设计文档分组。

## 触发与叫停

- [撤标签与重复触发的做法对比](撤标签与重复触发的做法对比.md)：并发组和取消机制、官方项目怎么处理中途撤标签和重复触发、四种做法对比、2026-10-25 触发实测。
- [GitHub事件实测](GitHub事件实测.md)：issue 事件的载荷里有哪些字段。
- [Actions平台事实_产物缓存重跑定时](Actions平台事实_产物缓存重跑定时.md)：产物、缓存、重跑、定时任务的平台事实，检查点和定时对账的依据。
